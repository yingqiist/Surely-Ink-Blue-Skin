# Surely-Ink-Blue-Skin
CSS for AO3 custom site skin.

This site skin uses an existing AO3 site skin as a base, with minor changes and bug fixes.

## Base
[Constellation AO3 site skin by thevalkyrieflies on tumblr](https://www.tumblr.com/thevalkyrieflies/799148971859787776/constellations-ao3-skin?source=share)

## Minor Changes
*   Restored sized header to AO3 default size
*   Restored AO3 logo (previously set to transparent)

## Bug Fixes
*   Fixed Edit Tag button that had double cloud borders
*   Fixed Subscribe, commit, submit type buttons not sharing the same style as the other buttons
*   Fixed Download button and dropdown to have the same style as other buttons
